# Lucid Master Extension Repository for Tachiyomi & Mihon

Master repository containing **44 extensions** (25 Manga & Comic extensions, including **E-Hentai**, and 19 Anime & Video extensions) with full tag search, filter lists, popularity sorting, and release updates intact.

## Quick Setup

### For Mihon, TachiyomiSY, TachiyomiJ2K, Yokai
1. Open **Settings** -> **Browse** -> **Extension repositories**.
2. Tap **Add repository**.
3. Paste:
```text
https://raw.githubusercontent.com/LucidFR-67/tachiyomi-extensions/main/index.min.json
```

### For Aniyomi (Anime Extensions)
1. Open **Settings** -> **Browse** -> **Anime extension repos**.
2. Tap **Add repository**.
3. Paste:
```text
https://raw.githubusercontent.com/LucidFR-67/tachiyomi-extensions/main/index.min.json
```

## Features
- **Full Tag Filtering:** Every extension contains compiled `getFilterList()` implementations for complex tag queries, genre inclusions/exclusions, and multi-criteria searches.
- **Sorting Modes:** Supports Latest Updates, Popularity, and Most Viewed sorting across all supported backends.
- **Zero Login E-Hentai:** Includes standalone `eu.kanade.tachiyomi.extension.en.ehentai` allowing public browsing without requiring account cookies.
- **Universal Fork Compatibility:** Compatible with Mihon, Tachiyomi, TachiyomiSY, TachiyomiJ2K, Yokai, Aniyomi, and Komikku.
